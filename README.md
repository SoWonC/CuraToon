## 프로젝트 소개

> 팀 프로젝트 큐레이툰에서 제가 맡았던 코드와 문서를 개인 저장소로 옮겨 정리한 것입니다.  
> 원본 그룹 저장소: [k-webtoon](https://github.com/k-webtoon)  
> - 프론트엔드: [k-webtoon-frontend](https://github.com/k-webtoon/k-webtoon-frontend)  
> - 백엔드: [k-webtoon-backend](https://github.com/k-webtoon/k-webtoon-backend)

<div style="text-align: left;"> 
  <h2 style="border-bottom: 1px solid #d8dee4; color: #282d33;">큐레이툰 (CuraToon)</h2>  
  <div style="font-weight: 700; font-size: 15px; text-align: left; color: #282d33;">큐레이툰(Curation + Webtoon)은 사용자 취향에 맞는 웹툰을 AI로 추천해 주는 사이트입니다.</div> 
</div> <br>

<div style="text-align: left;"> 
  <h2 style="border-bottom: 1px solid #d8dee4; color: #282d33;">About</h2>  
  <div style="font-weight: 700; font-size: 15px; text-align: left; color: #282d33;"> 
    웹툰 플랫폼은 대부분 인기작 위주로 보여줘서, 내 취향에 맞는 덜 알려진 작품은 찾기가 어렵습니다. </br></br>
    그래서 인기 순위 말고 사용자가 고른 웹툰과 검색한 내용을 바탕으로 비슷한 작품을 추천하는 걸 목표로 만들었습니다. </br></br>
    2025.03 ~ 2025.05, 4인 팀 프로젝트 / 담당: 서비스 기획, 마이페이지, 관리자 통계 페이지
  </div>
</div> <br>
